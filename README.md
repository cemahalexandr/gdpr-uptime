# gdpr-uptime

Внешний сторож лендинга GDPR и кабинета CRM. Работает у GitHub каждые 10 минут.

Зачем не у нас: сторож на том же сервере молчит, когда сервер лежит. Планировщик хостинга
serflow, где сторож стоял раньше, не выполняет задачи с 03.06.2026 (проверено 03.09.2026:
за сутки на аккаунте ни одного измененного файла, последний лог от 03.06).

Что проверяет: лендинг на румынском отдает 200 с текстом кнопки, прием заявок отвечает 405
на GET, health кабинета отдает HEALTHY. Каждая проверка повторяется дважды с паузой 20 секунд.
При падении шлет в Telegram Александру и в чат Claude Тех.

Секреты репозитория: TG_TOKEN (бот @tsemakhalex_bot), TG_CHATS (id через запятую).
